Usage of kent goal:
  kent goal show [--json] [--session <id>]
  kent goal set [--session <id>] <objective>
  kent goal pause [--session <id>]
  kent goal resume [--session <id>]
  kent goal clear [--session <id>]
  kent goal complete [--session <id>] [--confirm]

Show or change the goal that guides an active session.
Inside a Kent shell command, the command targets that session.
Otherwise, pass `--session <id>`.
Agents may set a goal only when their session has no active or paused goal.
Only humans may pause, resume, or clear a goal.
