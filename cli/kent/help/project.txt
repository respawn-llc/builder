Usage of kent project:
  kent project [path]
  kent project list
  kent project create --path <server-path> --name <project-name>

Find or create projects and their workspace attachments.

Commands:
  kent project [path]
    Print the project ID attached to `path`. Defaults to the current directory.

  kent project list
    List projects available from the current server.

  kent project create
    Create a project and attach its first server-visible workspace.

Examples:
  kent project
  kent project list
  kent project create --path /srv/repos/app --name app
